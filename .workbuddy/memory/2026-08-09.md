## 修复远程壁纸 CORS 无法加载 Bug（最终方案：manifest host 权限）

- **根因**：`newetab.js` 中 `bgImg.crossOrigin = 'anonymous'` 使浏览器以 CORS 模式加载远程壁纸，必应每日一图等不返回 CORS 头的壁纸源被浏览器拦截，背景空白
- **最终修复**（`Universal/manifest.json`，用户指定方案）：`host_permissions` 改为 `<all_urls>`、`*://*/*`，扩展获得跨域权限后 CORS 请求被放行。**不改动 `newetab.js` 加载逻辑**（此前曾先尝试 JS 降级方案，用户确认不需要，已 `git checkout` 完全还原）
- **收益**：远程壁纸展示 + 「保存壁纸」canvas 导出均正常（CORS 不再被拦截，canvas 不"污染"）
- **权衡**：放弃"权限最小化"决策，接受全局 host 权限的审核提示与攻击面增大
- **文档**：progress.md（Bug 记录、决策 6/7、权限精简章节补充、删除已解决的"跨域壁纸下载"遗留项）、README.md（多源壁纸 + 代码说明）已按最终方案同步
- **测试**：manifest.json JSON 合法、newetab.js 语法通过；未在真实浏览器环境实测

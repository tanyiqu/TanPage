# 2026-08-09

## TanPage 项目全面优化

按照前期分析报告的优化项，对 TanPage 扩展做了全面优化（聚焦主版本 Universal/）：

### 完成的优化
1. **Bug 修复**
   - `utils.js`：修复 `String.prototype.format` 对象模式失效（`args.key`→`args[key]`）
   - `newetab.js`：搜索词改用 `encodeURIComponent` 整体编码（原手动 replace 只替换首个）
   - `history.js`：maxResults 从 2147483647 降为 1000；修复跳过首条记录 Bug（改为过滤当前页 URL）
   - `background.js`：修复 XHR `readyState/status` 运算符优先级 Bug
   - 清理隐式全局变量（utils.js `_x/_y`、cutEngineLogo.js `dataUrl/w/h/mouseCoor`）
   - 清理所有业务代码 console.log

2. **功能恢复**：Universal 版右键菜单从空壳恢复为完整三项功能（默认引擎搜索/跳转链接/有道翻译），并适配 MV3（`alert`→`notifications`、`window.open`→`chrome.tabs.create`、http→https）

3. **权限精简**：manifest 移除 `<all_urls>`/`http://*/*`/`https://*/*`，host_permissions 只留 suggestion.baidu.com + fanyi.youdao.com；新增 notifications 权限

4. **新增功能**：设置"恢复默认"真正生效（通过 `chrome.runtime.sendMessage` 通知后台写回 DEFAULT_SETTINGS，保留本地壁纸）；默认配置收敛为 `DEFAULT_SETTINGS` 单一来源

5. **工程清理**：删除 8 个废弃文件（background-old.js、API.js、engines.js、manifest1.json、manifest - Chrome/Firefox.json、Universal.zip、extensions.sketch）；清理 HTML 注释模板与失效链接；popup 标题修正；setting.json 与 DEFAULT_SETTINGS 对齐

6. **文档**：重写 README.md，新建 progress.md

### 关键决策
- 以 `Universal/`（MV3）为唯一主版本，`Chrome/`、`FireFox/` 保留作归档不再维护
- 右键菜单功能以 Chrome 版实现为基准合并
- 注意：git rm 批量删除文件时曾误删 egs/tip 图片目录，已通过 git checkout 恢复（后改用逐文件 rm）
